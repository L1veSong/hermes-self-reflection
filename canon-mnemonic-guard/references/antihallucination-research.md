| 类型 | 特征 | sentinel 能力 |

## 豆包：6 种方案（由浅到深，可叠加）

### 方案一：分层隔离架构（RAG 知识库）
所有确定性事实封存进离线知识库 RAG。大模型只负责理解逻辑，不从脑子回忆事实。

> 模型回忆 = 随机概率必然错乱。知识库调取 = 固定文字死数据零错误。

### 方案二：行为溯源校验层
每次输出前强制三步自检：是否发起过检索记录？是否调用过工具日志？是否产生执行流水？没有行为日志 → 直接禁止输出结论。

### 方案三：双模型分流架构
- 主对话/构思/创意 → 便宜模型
- 事实核对/资料查证 → 低幻觉模型

### 方案四：思考链强制外化
所有内心推演必须全部明文写出来，不允许隐性思考。CMG 管不到推理层——架构边界。

### 方案五：对话记忆轻量化 + 时序分段
长对话上下文堆叠杂乱、时序混乱 → 幻觉最大诱因。切割分段、标注时间标签。

### 方案六：Harness 驾驭工程（终极方案）
在模型外层搭建独立管控外壳——独立判断、独立记忆、独立行为监管。大模型负责生成内容，驾驭外壳负责审判真假、纠正脑补。**sentinel 的设计目标。**

### 层级总结

| 层级 | 方案 | CMG 状态 |
|------|------|:--:|
| 浅层 | 自定义规则/Skill约束 | ✅ 已在做 |
| 中层 | RAG知识库 + 时序记忆 + 思考链公开 | ⚠️ 部分可做 |
| 高层 | 操作日志行为锁 + 双模型分流 | ⚠️ 部分可做 |
| 顶层 | Harness驾驭外壳 | ✅ sentinel 终极形态 |

## 策略决策

- **事后拦截已做到位**——再加强只是惩罚更狠，检测能力不会质变
- **事前注入是高杠杆方向**——铲掉幻觉的土壤（缺数据）比抓撒谎更有效
- **Harness外壳 = sentinel 的终极形态**——独立判断+独立行为监管已做，独立记忆(RAG)是下一步

## 三点共识

1. 真性幻觉是 LLM 概率生成架构的天生缺陷，无法根治
2. 当前可行路径 = 隔离而非治愈——保证用户看不到假话
3. 事前给数据 > 事后纠错

## 平台联动

多 Agent 平台架构下，CMG 从插件变中间件——从 17 个 hook 降为两个函数调用（pre_check + post_check），所有接入 Agent 自动共享同一套规则和拦截。
